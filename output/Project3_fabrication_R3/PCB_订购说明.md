# R3 PCB 与连接器订购说明

裸板上传 [Project3_R3_JLC_Gerber.zip](Project3_R3_JLC_Gerber.zip)。包内为 4 个铜层、2 个阻焊层、2 个丝印层、1 个板框、1 个 Excellon 钻孔文件，均放在 ZIP 根目录。加工要求以 [FABRICATION_NOTES.md](FABRICATION_NOTES.md) 和板厂回签为准。

| 下单项 | 当前设计条件 |
|---|---|
| 板材/层数/外形 | FR4、4 层、56×64.430 mm，单片出货 |
| 首板数量 | 建议 5 片，实际数量按订单确认 |
| 总厚 | 名义 1.6 mm，SMA 卡板处目标 1.60±0.05 mm |
| 叠层 | 课件对应 JLC04161H-7628；PP1/PP2 各 0.2104 mm，芯板 1.065 mm；供应商适用性待回签 |
| 外/内铜 | 35 µm / 15.2 µm，不能只用 oz 标签代替实际厚度确认 |
| 表面处理 | 当前工程和加工说明指定沉银；可用性待板厂回签。OSP 尚未确认为本设计条件 |
| 钻孔 | 10 个 0.30 mm 贯通电镀接地孔，焊环外径 0.60 mm |
| 阻焊/丝印 | 严格按文件，天线与馈线开窗；不加板内二维码/工艺字 |
| 加工约束 | 保持铜形与线宽，不统一调整阻抗线宽；L3 不加整面铜或铜平衡 |
| 装配 | 无钢网/自动 SMT 要求；SMA 中心针和上下四地脚按板边基准装配 |

J1 端接焊盘需允许铣边露铜，无侧壁电镀、半孔、金手指或倒角要求。关键 PP1 不能用于补足总板厚。板厂确认实际 Dk/Df、压合厚度、铜厚、沉银、卡板厚度与板边工艺后，手动审阅生产稿。

零件按 [BOM.csv](BOM.csv)：每板 1 个 Würth Elektronik **60312202114509**，50 Ω SMA 母头、1.6 mm 卡板。ANT1 不采购。嘉立创商城商品编号、库存、价格与可代购状态待核实；不得仅凭 SMA 接口相同替换型号。

若选择 OSP，必须同步确认工程、加工说明、订单参数和模型适用性；当前文档不作 OSP 性能认证。首板须测量 S11、方向图、极化与旁瓣。
