# Project 3 目标与要求：微带贴片天线阵（Patch Antennas Array）

> **来源**：`docs/04 RF circuit design - projects 2026.pdf`（EST3313 RF Circuit Design，Fall 2026）第 11、12、16 页。

| 项       | 内容                                             |
| -------- | ------------------------------------------------ |
| 课题编号 | Project 3                                        |
| 课题名称 | Patch antennas array（微带贴片天线阵）           |
| 工作频段 | 5.8 GHz（ISM 频段）                              |
| 实现形式 | 微带贴片单元 + 功分馈电网络 + 1×2 线阵，PCB 加工 |

## 2. 设计指标（课件第 16 页原文）

| #   | 指标           | 要求                  | 含义/说明                                                |
| --- | -------------- | --------------------- | -------------------------------------------------------- |
| 1   | 中心频率       | **5.8 GHz**           | 设计中心频点，S11 最低点应落在 5.8 GHz 附近              |
| 2   | 10 dB 阻抗带宽 | **> 150 MHz**         | S11 ≤ −10 dB 的连续带宽大于 150 MHz                      |
| 3   | 阵列规模       | **1×2**               | 两个贴片单元组成线阵                                     |
| 4   | 单元间距       | **0.5 λ₀**            | λ₀ 为 5.8 GHz 自由空间波长 ≈ 51.69 mm，故间距 ≈ 25.84 mm |
| 5   | 极化           | **单线极化**          | 单一线极化，不要求双极化/圆极化                          |
| 6   | 辐射方向       | **边射（broadside）** | 主波束垂直于阵面（法向）                                 |
| 7   | 旁瓣抑制比     | **> 10 dB**           | 旁瓣电平相对主瓣的抑制大于 10 dB                         |

## 3. 仿真设计过程

课件给出的参考工作流：

1. **微带贴片单元设计** —— 由传输线模型/腔模法估算贴片尺寸，HFSS 仿真优化至 5.8 GHz 谐振。
2. **功分馈电网络设计** —— 1 分 2 功分器（T 形结或威尔金森），含 50 Ω 匹配与阻抗变换。
3. **天线阵列结构设计** —— 1×2 排布、0.5 λ₀ 间距、单线极化、边射，含基板与接地/馈电过孔布局。
4. **联合仿真与优化** —— 单元 + 馈电网络 + 阵列整体联合仿真（HFSS，必要时与 ADS 电路/版图协同）。
5. **版图生成、加工与测试** —— 输出可制造版图（Gerber/钻孔）、实际投板加工、实测并与仿真对比。

## 5. 指标口径备注（避免验收争议）

1. **带宽**：课件写“> 150 MHz”为绝对带宽，按 S11 ≤ −10 dB 的连续频段计算；建议同时给出相对带宽便于说明。
2. **旁瓣抑制比**：主瓣峰值功率（或幅度）与最大旁瓣（通常是紧邻的第一旁瓣）峰值功率（或幅度）的比值。同时给出更严格口径（主瓣以外任意方向的最大电平）的数据。
3. **0.5 λ₀**：按 5.8 GHz 自由空间波长 λ₀ = c / 5.8 GHz ≈ 51.688 mm 计算，间距 ≈ 25.844 mm。
4. **增益、辐射效率、驻波比、轴比、尺寸上限等指标**：课件无要求，不用管。
